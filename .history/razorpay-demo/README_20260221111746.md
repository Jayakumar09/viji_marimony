# Razorpay Demo - Test Mode Integration

This is a standalone demo project for testing Razorpay payment integration in test mode.

## 🚀 Quick Start

### 1. Install Dependencies

```bash
cd razorpay-demo
npm install
```

### 2. Configure API Keys

1. Copy `.env.example` to `.env`:
   ```bash
   copy .env.example .env
   ```

2. Get your Test API keys from [Razorpay Dashboard](https://dashboard.razorpay.com/app/keys)

3. Update `.env` with your test credentials:
   ```
   RAZORPAY_KEY_ID=rzp_test_your_key_id
   RAZORPAY_KEY_SECRET=your_key_secret
   ```

### 3. Start the Server

```bash
npm start
```

The server will start on `http://localhost:5003`

### 4. Open the Demo UI

Open your browser and go to: `http://localhost:5003`

## 🔌 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/health` | Health check |
| GET | `/api/config` | Get Razorpay config (key ID) |
| GET | `/api/test-cards` | Get test card details |
| POST | `/api/create-order` | Create new payment order |
| POST | `/api/verify-payment` | Verify payment signature |
| GET | `/api/payment/:id` | Fetch payment details |
| GET | `/api/order/:id` | Fetch order details |
| POST | `/api/refund` | Refund a payment |

## 📝 Example API Usage

### Create Order

```bash
curl -X POST http://localhost:5003/api/create-order \
  -H "Content-Type: application/json" \
  -d '{"amount": 100, "currency": "INR"}'
```

### Verify Payment

```bash
curl -X POST http://localhost:5003/api/verify-payment \
  -H "Content-Type: application/json" \
  -d '{
    "razorpay_order_id": "order_xxx",
    "razorpay_payment_id": "pay_xxx",
    "razorpay_signature": "xxx"
  }'
```

## ⚠️ Important Notes

1. **Test Mode Only**: This demo uses Razorpay Test Mode. No real money will be deducted.

2. **API Keys**: Never expose your Key Secret in frontend code. It should only be used on the server.

3. **Webhooks**: For production, set up webhooks to handle payment events asynchronously.

4. **Security**: Implement proper validation and security measures before going to production.

## 🛠️ Troubleshooting

### Server not starting?
- Check if port 5001 is available
- Verify your `.env` file has correct values

### Payment not working?
- Verify your API keys are correct
- Check if you're using Test Mode keys (start with `rzp_test_`)
- Check browser console for errors

### CORS errors?
- Make sure the server is running
- Check `FRONTEND_URL` in `.env` matches your frontend URL
