📋 How to Get Instamojo Credentials

  1. Go to Instamojo.com
  2. Sign up (quick process - just email & phone verification)
  3. Go to Dashboard → API & Plugins
  4. Copy your API Key, Auth Token, and Salt
  5. Update the .env file in instamojo-demo folder
  6. Restart the server

Note: Test mode works immediately after signup. No business verification needed for testing!
